# Lista de Exercícios: Lógica com JavaScript

#### 1. Verificador de Idade (Condicionais)

Para entrar em um evento de tecnologia, a idade mínima é **18 anos**. Crie uma variável `idade`. Se a idade for maior ou igual a 18, imprima "Entrada permitida". Caso contrário, imprima "Entrada negada: você precisa ter pelo menos 18 anos".

#### 2. Calculadora de Média (Operadores e Condicionais)

Um professor precisa automatizar as notas. Crie três variáveis (`nota1`, `nota2`, `nota3`). Calcule a média aritmética. Se a média for **7 ou superior**, imprima "Aprovado". Se for entre **5 e 6.9**, imprima "Recuperação". Abaixo de 5, imprima "Reprovado".

#### 3. Par ou Ímpar (Operadores Aritméticos)

O operador de resto da divisão `%` é muito útil. Crie uma variável `numero`. Use uma condicional para verificar se o número é **par** ou **ímpar** e exiba o resultado no console.

#### 4. Tabuada Dinâmica (Loop For)

Para ajudar crianças a estudarem matemática, crie um programa que defina uma variável `multiplicador`. Use um laço `for` para imprimir a tabuada desse número do 1 ao 10 (ex: 5 x 1 = 5, 5 x 2 = 10...).

#### 5. Contagem Regressiva (Loop While)

Um foguete está prestes a decolar! Crie um programa que utilize o laço `while` para fazer uma contagem regressiva de **10 até 0**. Ao final da contagem, imprima "Decolar! 🚀".

#### 6. Sistema de Login Simples (Operadores Lógicos)

Crie duas variáveis: `usuarioCadastrado` e `senhaCadastrada`. Em seguida, crie `tentativaUsuario` e `tentativaSenha`. Use o operador lógico `&&` (E) para verificar se o login e a senha coincidem. Imprima "Login efetuado com sucesso" ou "Usuário ou senha incorretos".

#### 7. Somatório de Números (Loop For)

Imagine que você precisa somar todos os números de 1 a 100. Use um laço `for` e uma variável acumuladora (ex: `let soma = 0`) para calcular esse total e exibi-lo ao final.

#### 8. Conversor de Moedas (Operadores Aritméticos)

Crie uma variável `valorEmReal`. Sabendo que a cotação do dólar está em **$ 5.00** (valor hipotético), calcule e imprima quanto esse valor vale em dólares.

> Dica: $Valor_{Dolar} = Valor_{Real} / Cotacao$

#### 9. Classificador de Clima (Condicionais)

Crie uma variável `temperatura`.

* Se for maior que 30: "Está muito quente!".
* Se estiver entre 15 e 30: "Clima agradável".
* Se for menor que 15: "Está frio!".

#### 10. O "Pulo do Gato" (Loop e Condicional)

Crie um loop que percorra os números de **1 a 20**. Para cada número, verifique:

* Se o número for divisível por 3, imprima "Fizz".
* Se o número for divisível por 5, imprima "Buzz".
* Se não for nenhum dos dois, imprima o próprio número.
*(Este é um desafio clássico de lógica chamado FizzBuzz!)*

#### 11. Comparador de Números (Comparadores)

Crie duas variáveis, `num1` e `num2`. O programa deve comparar as duas e imprimir: "O primeiro é maior", "O segundo é maior" ou "Os números são iguais".

#### 12. Calculadora de IMC (Aritméticos e Condicionais)

Crie as variáveis `peso` (kg) e `altura` (metros). Calcule o Índice de Massa Corporal (IMC). Se o IMC for menor que 18.5, imprima "Abaixo do peso". Se estiver entre 18.5 e 24.9, "Peso normal". Acima disso, "Acima do peso".

> Fórmula: $IMC = peso / altura^2$

#### 13. Verificador de Ano Bissexto (Lógicos e Operadores)

Um ano é bissexto se for divisível por 4 **e** não for divisível por 100, **ou** se for divisível por 400. Crie uma variável `ano` e verifique se ele segue essas regras usando os operadores `&&`, `||` e `%`.

#### 14. Senha de Acesso (Loop While)

Crie um programa que tenha uma variável `senhaCorreta = "1234"`. Crie uma variável `tentativa`. Use um laço `while` que simule o usuário digitando a senha. Enquanto a `tentativa` for diferente da `senhaCorreta`, o programa deve imprimir "Senha Incorreta, tente novamente". Quando acertar, imprima "Acesso Permitido".

#### 15. Tabuada Completa (Nested Loops - Loop dentro de Loop)

Este é um desafio de mestre! Use dois laços `for` (um dentro do outro) para imprimir as tabuadas do 1 ao 5 completas (do 1 ao 10 para cada número).

#### 16. Média de uma Sequência (Loop For)

Crie um programa que some todos os números de 1 a 50 e, ao final, calcule a média aritmética dessa soma (Soma total dividida pela quantidade de números).

#### 17. Classificador de Triângulos (Condicionais e Lógicos)

Crie três variáveis `ladoA`, `ladoB` e `ladoC`. Verifique:

* Se todos os lados forem iguais: "Equilátero".
* Se apenas dois forem iguais: "Isósceles".
* Se todos forem diferentes: "Escaleno".

#### 18. Desconto Progressivo (Operadores e Condicionais)

Uma loja dá desconto dependendo do valor da compra:

* Compras acima de R$ 500,00: 15% de desconto.
* Compras entre R$ 200,00 e R$ 500,00: 10% de desconto.
* Abaixo de R$ 200,00: sem desconto.
Imprima o valor final a ser pago.

#### 19. Parada Estratégica (Loop com Break)

Crie um loop `for` que conte de 1 a 100. No entanto, você deve definir uma variável `numeroDaSorte`. Quando o loop chegar no número da sorte, ele deve imprimir "Número encontrado!" e **parar** a execução (use o comando `break`).

#### 20. Contador de Ímpares (Loop e Operadores)

Crie um programa que percorra os números de 1 a 30. No entanto, o programa só deve imprimir no console os números que forem **ímpares**.
